## Selection governance

- Manbalarni foydalanuvchi vazifasi, sinov darajasi, maintenance holati, accessibility va litsenziya bo'yicha tanlash.
- Biror library taniqli bo'lishi dizaynni avtomatik original qilmaydi.
- Knowledge extraction: `source URL → screenshot/context → observed pattern → limit → reviewer → validated card`.
- Professional dizaynni internetdan nusxalash emas, original kompozitsiya va real task uchun interpretatsiya qilish.
