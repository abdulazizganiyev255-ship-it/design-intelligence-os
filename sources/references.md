# Tekshirilgan tashqi reference'lar

Manbalar format, accessibility va audit metodikasi uchun keltirilgan. DIO ichki score weights/tizim qoidalari **biz ishlab chiqqan qarorlar**, tashqi standard emas.

1. **W3C — WCAG 2.2**: https://www.w3.org/TR/WCAG22/  (a11y standard, AA as target)
2. **W3C — Contrast Minimum**: https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum (normal text 4.5:1, large text 3:1)
3. **Nielsen Norman Group — 10 Usability Heuristics**: https://www.nngroup.com/articles/ten-usability-heuristics/ (UX heuristic guidance)
4. **Nielsen Norman Group — How to Conduct Heuristic Evaluation**: https://www.nngroup.com/articles/how-to-conduct-a-heuristic-evaluation/ (heuristic audit does not replace user research)
5. **Agent Skills specification**: https://agentskills.io/specification (SKILL.md required name/description frontmatter)
6. **OpenAI skill authoring examples**: https://github.com/openai/skills (examples; reuse only within license)
7. **GitHub agent instructions support**: https://docs.github.com/en/copilot/reference/custom-instructions-support (`AGENTS.md`, repository instructions support depends on client)
8. **GitHub Actions usage**: https://docs.github.com/en/actions/concepts/billing-and-usage (private repo free quota/charge considerations)

## Litsenziya va bilish darajasi siyosati

- GitHub repository URL borligi ko'chirishga ruxsat bermaydi. Har safar LICENSE tekshiriladi.
- UI screenshotlari **ko'rib chiqish va tahlil** uchun; original assetlar, kodlar, matnlar identik ko'chirilmaydi.
- External blog fikri fakt emas; mahsulot performance da'vosi mustaqil test talab qiladi.
- `source_url`, `date_checked`, `evidence_type`, `permission_status` Reference Card'da qayd etiladi.
