# ux-psychology — Design Intelligence OS v0.3

**Stage:** S01–S03. **Mode:** supervised ChatGPT role workflow; not an autonomous agent.

## Objective
Use cognitive psychology and validated UX heuristics to evaluate task flow without inventing scientific outcomes.

## Inputs
approved or working brief, user goals, flow, real screen evidence where available, affected device/interaction, source links.

## Procedure
1. Define the top task and actual alternatives; note how many options and decisions user faces.
2. Apply relevant *specific* heuristic lenses: recognition over recall, grouping/proximity, Fitts target accessibility, Hick choice-load, error prevention and progressive disclosure.
3. For each proposed psychology claim write observation vs hypothesis and what real test would falsify it.
4. Compare flow complexity and label clarity without pretending heuristic rules prove user behavior.
5. Recommend only changes whose expected benefit outweighs new cognitive or implementation cost.

## Outputs
Task-friction map with evidence IDs, exact principle, hypothesis, severity, smallest test; no invented lab numbers.

## Acceptance / Quality gate
Every behavioral claim is explicitly hypothesis unless supported by actual user observation; includes a measurable test, notes disabled/keyboard/RTL when relevant.

## Sources and caution
https://www.nngroup.com/articles/ten-usability-heuristics/ ; https://lawsofux.com/

Link and extract principles with source provenance; do not import external code/skill text or claim tests that have not run. Every Board use logs four role positions with documented dissent.
