# typography-system — Design Intelligence OS v0.3

**Stage:** S05. **Mode:** supervised ChatGPT role workflow; not an autonomous agent.

## Objective
Design semantic typography roles for legibility, hierarchy and number-dense mobile interfaces.

## Inputs
selected visual target, language/content, platform/dynamic type constraints, longest Uzbek labels and currency amounts.

## Procedure
1. Specify display/title/heading/body/label/caption/numeric roles and font fallback.
2. Choose size, leading, weights and tracking by role; test 320px and text scaling rather than only default 390px.
3. Set numeric tabular alignment where amounts are columns; use proper minus and so‘m forms.
4. Validate wrapping/truncation of long labels, voiceover reading order and low-priority metadata legibility.
5. Compare real prototype images and correct over-dense type before tokens freeze.

## Outputs
type scale, usage matrix, truncation strategy, evidence of sample renders.

## Acceptance / Quality gate
No critical text clipped; text scale strategy documented; numerals and labels readable in each required state.

https://github.com/primer/react ; https://www.w3.org/TR/WCAG22/
